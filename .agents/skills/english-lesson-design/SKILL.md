# 英语教学内容设计

- 把教学目标写成观众结束后可以说出、判断或修正的一件事。先定学习者水平及语域，再写例句。
- 用最小对比例证明一个区别。区分规则、习惯和语域选择；标出看似反例但属于不同用法的边界。口音、拼写风格和语速有意选择，不把单一变体说成唯一正确。
- 练习先给任务和足够的答题留白，答案放在揭晓处。回答前的静默可标在时间线，不让 TTS 伪造停顿。
- 代表性片段覆盖最容易出错的一处：能听懂、能看懂、能用。把例句、语音和画面服务的同一目标写进总纲，等用户确认后再推进。
