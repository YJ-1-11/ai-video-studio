# 教学画面与动态表达

- 给每个画面一个任务：建立语境、做对比、给练习、揭晓或回顾。例句变化优先保留相同视线锚点，让观众看到变化的词或结构，而不是重新找位置。
- 静态审核先看信息主次、字号、留白、对比和字幕占位。动态审核再看揭晓时机和阅读停留；运动必须说明发生了什么，装饰可省。
- 画面和旁白竞争时保住教学信息：同一时刻只突出一个焦点，字幕不遮例句。先试目标尺寸，再检查练习前后和最长句。
- 按获批总纲选择手法。不要把卡片、字幕位置或节拍模板视为固定风格。
